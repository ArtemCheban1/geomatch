# Геомач — план проєкту

**Мета:** веб-застосунок для геореференсингу: накладати сканові та фото старих карт на сучасну мапу
за контрольними точками, потім склеювати кілька аркушів в одну карту, порівнювати епохи та
додавати власні об'єкти.

---

## Як це працює (коротко про математику)

1. Користувач ставить пари точок: **піксель на скані ↔ координата на мапі** (Ground Control Points, GCP).
2. Усі розрахунки йдуть у площині Web Mercator (EPSG:3857) — тій самій, у якій малюється мапа.
3. За точками методом найменших квадратів (QR-розклад, з нормалізацією координат) підбирається
   перетворення «зображення → мапа»:

   | Перетворення          | Мін. точок | Коли використовувати |
   |-----------------------|-----------:|----------------------|
   | Helmert (подібність)  | 2 | зсув + поворот + масштаб, без деформацій |
   | Афінне                | 3 | стандарт для більшості карт |
   | Проєктивне            | 4 | фото карти під кутом (перспектива) |
   | Поліном 2 / 3 порядку | 6 / 10 | старі карти в іншій проєкції, плавні викривлення |
   | Thin Plate Spline     | 3 | «гумовий лист»: сильно деформовані карти, точно через кожну точку |

4. Якщо точок більше за мінімум — рахуються **нев'язки** (наскільки кожна точка не вписується в
   модель, у метрах на місцевості) і **RMSE**. Це показує помилково поставлені точки.
5. Зображення **перепроєктовується** (інверсне перетворення + білінійна інтерполяція) у прямокутний
   растр у Web Mercator у фоновому потоці (Web Worker) і показується на мапі як шар з прозорістю.

## Технічний стек

- **Vite + TypeScript**, без фреймворку — мінімум залежностей, швидкий старт.
- **MapLibre GL JS** — відкрита векторно/растрова мапа (без ключів, з можливістю пізніше
  під'єднати Google/Mapbox).
- Власне математичне ядро (`src/geo/`) — без зовнішніх GIS-бібліотек, покрите тестами (Vitest).
- Web Worker для перепроєктування зображень (інтерфейс не підвисає).

### Структура

```
src/
  geo/
    linalg.ts        найменші квадрати (Householder QR), розв'язання систем
    transforms.ts    Helmert, афінне, проєктивне, поліноми 2/3, TPS; інверсії
    georef.ts        GCP → перетворення, нев'язки, RMSE
    mercator.ts      Web Mercator
    warp.ts          перепроєктування растру
    warp.worker.ts   фоновий потік
  ui/
    imageView.ts     перегляд скану, точки, обрізка
    mapView.ts       мапа, підкладки, накладки, маркери
  state.ts           модель проєкту, автозбереження
  io.ts              імпорт/експорт
  main.ts            зв'язування інтерфейсу
tests/               тести математики
```

## Відкриті питання

1. Де зберігати проєкти надалі — лише локально (файл) чи потрібен сервер і акаунти?
2. Який типовий розмір сканів? (від цього залежить, коли переходити на тайлування.)
3. Чи потрібні точні системи координат старих карт (Пулково-42, CK-42, аркуші за номенклатурою),
   чи достатньо прив'язки по точках?
4. Google Maps — потрібен для супутника кращої якості чи лише як альтернатива?
