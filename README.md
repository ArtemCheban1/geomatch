# Геомач

Геореференсинг старих карт у браузері: завантажте скан або фото карти, поставте 3–4 пари
контрольних точок (місце на зображенні ↔ те саме місце на мапі) — і карта накладеться на сучасну
супутникову/гібридну мапу з правильним масштабом, поворотом і розташуванням.

План розвитку — у [PLAN.md](PLAN.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).

Інші команди:

```bash
npm test          # тести математики
```

```bash
npm run build     # production-збірка в dist/
```

## Як користуватися

1. **+ Додати карту** (або перетягніть файл у вікно).
2. Знайдіть місцевість на правій мапі (пошук, підкладка «Гібрид»/«Супутник»).
3. Клікніть характерне місце на зображенні, потім те саме місце на мапі. Повторіть 3–4 рази,
   розносячи точки по кутах карти.
4. Слідкуйте за похибкою в таблиці та червоними лініями на мапі; перетягуйте точки для уточнення.
5. За потреби змініть перетворення (проєктивне для фото під кутом, поліном/TPS для викривлених карт)
   і обріжте зайве (✂ Обрізка).
6. **Файл → Експорт** — PNG + world file для QGIS, або точки у форматі QGIS `.points`.

Клавіші: `A` точки · `C` обрізка · `V` огляд · `Esc` скасувати · `Del` видалити точку ·
`O` показати/сховати накладку · `[` `]` прозорість.

## Підкладки

Безкоштовні, без ключів: Esri World Imagery (супутник), Esri Reference (дороги, підписи),
OpenStreetMap, OpenTopoMap. Для інтенсивного використання дотримуйтесь умов цих сервісів;
Google Maps можна під'єднати пізніше (потрібен API-ключ).
